# Dashboard Screenshot Notes

The PNG files in `docs/screenshots/` represent the final dashboard views expected from the Metabase layer:

- `kpi_dashboard.png`
- `revenue_at_risk_dashboard.png`
- `customer_segments_dashboard.png`
- `retention_priority_dashboard.png`

When Metabase is running through Docker Compose, recreate these from live data by opening `http://localhost:3000`, navigating to each dashboard tab, and replacing these files with browser screenshots.
