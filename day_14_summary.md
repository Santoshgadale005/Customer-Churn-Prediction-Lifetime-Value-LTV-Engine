# Day 14: Streamlit Frontend & Cloud Infrastructure foundations

## Overview
Today, we created a fully functional frontend using Streamlit and prepared the infrastructure setup for cloud deployments on Render.

## Accomplishments
- ✅ **Streamlit Interface:** Built `streamlit_app.py` to allow end-users to input features (tenure, monthly charges, total charges) and view predictions.
- ✅ **Inference Binding:** Connected the frontend with the FastAPI backend prediction endpoint (`http://127.0.0.1:8000/predict`).
- ✅ **Cloud Infrastructure:** Created `render.yaml` configuration to declare our service deployment model on Render.
